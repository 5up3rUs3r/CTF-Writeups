## About

These writeups document my solutions for CyberGame 2026. As an international participant from Kenya, placing 33rd globally with 7888 points across a 10-week national-qualifier CTF was a strong result. Challenges covered offensive security (ORM injection, PowerShell jailbreak, web exploitation), cryptography (XOR, encoding layers, elliptic curves), forensics (PCAP covert channels, steganography, Office/PDF forensics, drone telemetry), and malware analysis/reversing.
